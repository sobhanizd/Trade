# Translations (English / فارسی) and RTL

The app supports **English (`en`)** and **Persian (`fa`, right-to-left)**. The
language is stored in the `cp_lang` cookie (drives rendering) and in the user's
settings (`language`, used for alerts and the AI explainer). The root layout sets
`<html lang dir>`; Persian uses the Vazirmatn font.

## API

```ts
import type { Dict } from "@/lib/i18n";

// Per-file dictionary: identical shape in both languages. Functions for text with values.
const L = {
  en: { title: "My plan", months: (n: number) => `${n} months` },
  fa: { title: "برنامهٔ من", months: (n: number) => `${n} ماه` },
} satisfies Dict<unknown>;

// Server component:
import { getL, getLocale } from "@/lib/i18n/server";
const t = await getL(L);            // t.title, t.months(3)
const locale = await getLocale();   // for fmtDate/timeAgo/strategyName(…, locale)

// Client component:
import { useL, useLocale } from "@/lib/i18n/client";
const t = useL(L);
const locale = useLocale();
```

Shared bilingual helpers:
- `src/lib/plain.ts` — `strategyName(id, l)`, `strategyIdea(id, l)`, `statePlain(state, l)`,
  `timeframePlain(tf, l)`, `timeframeWord(tf, l)`, `conditionPlain(id, fallback, l)`,
  `exitReasonPlain(reason, l)`, `rrPlain(rr, l)`, `coinLabel(symbol, l)`.
- `src/lib/i18n/texts.ts` — `actionWord`, `verdictText(verdict, l)` (BUY/WAIT/SELL
  headline + reasons), `planLineReason`, `planNoteText`, `errorText(msg, l)` (wrap
  any API error shown to the user).
- `src/lib/format.ts` — `fmtDate(d, withTime, locale)`, `timeAgo(d, now, locale)`.
  Prices and numbers keep Latin digits in both languages (like most exchanges).

## Rules

1. **Every user-visible string** goes through a dictionary: headings, labels,
   buttons, placeholders, `aria-label`s, `title`s, alt text, empty states,
   errors, confirm() texts, page `metadata.title` (use `generateMetadata` with
   `getL`). Ticker symbols (BTC, ETH…), "€", "%", numbers stay as they are.
2. **RTL-safe layout**: use logical Tailwind utilities — `ms-/me-` (not `ml-/mr-`),
   `ps-/pe-` (not `pl-/pr-`), `start-/end-` (not `left-/right-`), `text-start/
   text-end` (not `text-left/right`), `border-s/border-e`, `rounded-s/rounded-e`.
   Add `className="flip-rtl"` to direction-bearing icons (ChevronRight, ArrowRight).
   Text arrows: English "→", Persian "←".
3. **Numbers/prices** inside sentences: wrap in an element with class `ltr`
   (or `tabular`) so `-€0.30` and `1.4×` keep their order in RTL.
4. **Charts** (lightweight-charts) stay left-to-right: their container has `dir="ltr"`.
5. Persian must be **easy, everyday Persian** for a non-professional reader; when a
   technical term is unavoidable, add a short explanation in parentheses.
